## Standing constraints (carry into every session)

- **`csl-orig` is read-only to agents** — corrections applied only with explicit M.G. authorization,
  via the canonical workflow (XML validation before commit; no BOMs).
- **Maintainer noise sensitivity** — one consolidated PR per month, batched follow-ups, edit-in-place;
  never per-word issues, never bot-applied edits.
- **Cologne `servepdf` sustained-429s from this IP** — scan fetches from a different network or
  server-side only; polite rates always.
- **The LLM TYPO pass is stochastic** — never blindly re-run or overwrite a committed triage package;
  recall grows by union-across-runs only.
- **Model attribution** — report tier AND exact version (e.g. Opus 4.8 `claude-opus-4-8`) for every
  step of every run, per-phase in multi-agent workflows.
